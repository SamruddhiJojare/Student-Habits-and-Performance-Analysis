# 📊 Student Habits vs Academic Performance : EDA Project

🚀 I'm excited to share my recent **full-fledged Exploratory Data Analysis (EDA) project**, investigating the impact of student habits on academic performance. This project took me through the entire data analysis pipeline, from initial cleaning to deriving impactful insights.

---

## 🔧 Tools & Libraries Used

- **Python**
- **Pandas** – for data manipulation  
- **Matplotlib** and **Seaborn** – for data visualization

---

## 🧠 Key Concepts Applied

- **Data Cleaning**: Handling missing values and removing inconsistencies to ensure data quality.
- **Univariate Analysis**: Examining the distribution of individual variables to understand their characteristics.
- **Bivariate Analysis**: Exploring relationships between pairs of variables, with a focus on predicting exam scores.
- **Multivariate Analysis**: Using correlation analysis to uncover relationships between multiple factors.
- **Feature Engineering**: Creating a `total_screen_time` variable to consolidate screen usage.

---

## 📌 Key Insights

From the analysis, several key relationships emerged:

- **Study time** is a strong indicator of exam scores. Students who spend more time studying tend to achieve higher grades.
- **Increased screen time** (social media and Netflix) shows a modest link to lower grades.
- **Students with better mental health** tend to achieve higher exam scores.
- Factors such as **parental education level, sleep hours, exercise frequency**, and **attendance percentage** do not show a strong connection with exam scores.
- The **total screen time** aligns with what we'd expect, given the time spent on social media and Netflix.
